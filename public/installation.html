Installation status

Charme is an unsigned development preview for Apple Silicon Macs. A release download will appear here after native launch and distribution checks pass.

Try it now

Open the widget demo or explore Collector Studio. Browser changes reset when you reload. No installation or account is needed.

Run from source

For developers: install Node.js 22.12 or newer and use the repository’s committed lockfile.

git clone https://github.com/Stang-715/Charme.git
cd Charme
npm ci
npm test
npm start

This launches a development Electron app. It is not a signed or notarized installer. Do not disable macOS security protections to open an unknown binary.

Existing preview users

  1. Export a .charme backup before updating.
  2. Quit Charme through its tray menu before opening a different build.
  3. Check the build identifier in Settings.
  4. Keep your data folder intact. Older builds may refuse newer data schemas.

Use Data folder in the app to locate your actual storage directory. Removing the application does not mean your saved notes and history should be deleted.

What remains to verify

Native focus and click-through behavior, VoiceOver, monitor changes, sleep/lock behavior and sustained performance still need complete acceptance evidence.
