# Charme implementation plan

## Product
A transparent, always-on-top desktop keychain with a 45-minute focus timer in its chrome ring. Hanging charms provide hydration logging, a glass task panel, a selectable duck or car, and a customizable neon glass name tag. Pointer interaction applies impulses to damped pendulum motion. All personal data stays on the user's computer.

## Architecture
- Electron owns the transparent window, tray, desktop notifications, window placement and lifecycle. A narrow preload bridge exposes validated actions; renderer has no Node access.
- React and Three.js render the interface and load GLB assets generated by Magnific. Do not hand-model meshes. Dynamic timer, name and task controls are accessible HTML overlays.
- A Node service bound only to 127.0.0.1 serves the local dashboard. Same-origin checks and a per-session token protect mutations. Use an OS-assigned port to avoid collisions.
- Persist settings, tasks, hydration events and focus sessions in Electron's per-user application-data directory. Serialize writes, atomically replace snapshots, and retain a recoverable backup. Provide a dashboard export and an Open data folder action.

## Behavior
- Start a 45-minute focus period automatically on launch; transition into 15-minute rest and then focus. Derive remaining time from persisted timestamps so sleep and restart do not reset it. A small reset control starts a fresh focus period. Record completed focus intervals without duplicate logs.
- Default hydration goal: five glasses per local calendar day. Allow changing the goal. Clicking the bottle records one drink and animates a refill; show progress and permit undo. Reset daily totals on local date rollover, preserving history. Offer a configurable reminder interval.
- Clicking the notebook opens a glassmorphic panel with add, complete, reopen and delete actions. Persist immediately and synchronize with the browser dashboard.
- Choose car or duck, edit the neon name, drag the widget, toggle always-on-top, and quit from the tray. Respect reduced motion and provide keyboard access.
- Dashboard displays today's water, task completion, focus sessions and historical daily totals; no hosted backend or account required.

## Delivery sequence
1. Inspect references and repository; generate one Magnific image and GLB to validate asset quality and integration.
2. Implement and test persistence, timer transitions, hydration rollover and task commands.
3. Build Electron shell and localhost dashboard, including security boundaries and synchronization.
4. Generate remaining Magnific assets, assemble the keychain, add pendulum motion and functional overlays.
5. Verify desktop interactions, restart persistence, browser updates, offline operation and visual fidelity.
6. Package macOS and Windows through GitHub Actions; document development and installation. Build and launch the local macOS artifact. Publish source and release artifacts after repository authentication is available.

## Acceptance evidence required
- Running transparent desktop window with all requested charms and the two decorative choices.
- Timer tests at focus/rest boundaries, across restarts and sleep.
- Water goal, refill interaction, undo and day-rollover tests.
- Task CRUD and completion demonstrated in both widget and dashboard after restart.
- Visual check against both references, including chrome, glass, neon and pointer swing.
- Magnific provenance recorded for every 3D model; no procedural replacement models.
- Installable download, README, GitHub source and successful platform packaging checks. Unsigned platform limitations documented accurately.
