## Deliberate release limits

No verified downloadable installer is advertised. Installation status points to source setup and existing native acceptance limitations. Native capture, VoiceOver, all failure states and sustained performance are not certified by this update.

The browser widget fixture does not implement the full native timer service. The landing page explicitly separates browser capabilities from macOS behavior.
